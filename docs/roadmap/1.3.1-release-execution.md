# Mandatory 1.3.1 release execution

- **Status:** active
- **Owning queue item:** [RELEASE-019](active-work.md#x-release-019-require-explicit-completion-or-approved-deferral-of-every-release-goal)
- **Completion / archival evidence:** pending final 1.3.1 qualification and publication

This checklist keeps final release execution separate from the feature goals
that execution requires to be complete. The user approved this correction to the
COURSE-004 and RELEASE-019 self-dependencies. No goal moves to a future release,
no acceptance requirement is waived, and the release cannot publish until all
18 goals in [the manifest](release-goals.json) and the CLI release gates pass.

- [ ] Complete every remaining 1.3.1 roadmap goal and reconcile included issues,
  reviews, branches and worktrees through the contribution sweep.
- [ ] Assemble the selective patch on `release/1.3.x`, excluding unrelated 1.4 work.
- [ ] Require contribution readiness, then complete the release plan and prepare
  sequence with truthful notes and declared version mirrors.
- [ ] Qualify the exact final 1.3.1 candidate on every required platform through
  the declared host, worker and CI policy. Preserve original native deadlines,
  failed evidence and all mandatory phases.
- [ ] Pass release check, current lifecycle/receipt checks and every artifact and
  package gate against that exact prepared candidate.
- [ ] Publish only the exact qualified commit and artifacts after all gates pass.
- [ ] Verify the published release, approved film and collateral links, latest
  release documentation, tag/branch synchronization and final contribution sweep.
- [ ] Close the milestone only after all preceding requirements are proven.

These steps remain requirements of 1.3.1. Completing COURSE-004 or RELEASE-019
does not claim that this checklist, native qualification or software publication
has completed. [The active roadmap](active-work.md) remains feature authority.
