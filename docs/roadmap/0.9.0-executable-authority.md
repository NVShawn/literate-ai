## Outcome

Make the framework's documented taxonomy, dependency, deterministic-execution, and
host-platform contracts executable through one Python authority at each boundary.
Skills route judgment to those services instead of asking the model to reproduce
mechanical work. This program implements [ADR 0030](../decisions/0030-executable-cross-layer-authority.md)
for the 0.9.0 release.

## Ordered delivery

   tests and prove that the ordinary gate launches no coding CLI or live model task.
   Retain explicit `litai worker verify-model` qualification.

These repairs are first because current HEAD cannot produce trustworthy broad-gate
evidence until they land.

### 2. Make directory taxonomy one executable service

5. Make the initialized skill set a declarative complete catalog or validated subset;

### 3. Centralize host/operator path policy

1. Add an injectable platform-family/path-policy value with semantic config, data,
   cache, state, managed-tool, install, temporary, and short-staging roots.
2. Implement ADR 0031's Linux/macOS `$HOME/.config/literate-ai` user-config root and

   root. This explicit project convention supersedes the earlier tentative native
   macOS Application Support option.
3. Migrate user config and event state, tool bootstrap, installer/SSH resolution,
   Bazelisk custody, remote short staging, and repeated `BUILD_DIR`/`OBJ_DIR` fallbacks.
4. Ship the dry-run-first 0.8.x migration in ADR 0031. Detect legacy locations without

5. Document standalone bootstrap and target-tool exceptions and add an AST/static gate

Implemented first slice (2026-09-01): `user_paths.py` owns injected OS roots and private
directory custody; `user_assets.py` owns override precedence and migration diagnostics;
`litai config paths/migrate` expose both. Worker, test, release, MCP, event, and sample
consumers use these services. The supplied catalog was explicitly migrated and three
reachable workers produced current observations; Windows validation awaits host-key
trust rather than weakening SSH verification.

Completed audit slice (2026-09-01): the user-root policy is distinct from the smaller
`HostSystemPaths` policy for `os-release`, AppArmor, `ldconfig`, and sandbox runtime or
virtual roots. Linux/macOS/Windows table tests cover both surfaces. The AST gate now
rejects ambient home and host-root environment reads plus absolute `Path(...)` literals
outside the owner; remote target programs and dependency-free stage-zero code remain
explicitly bounded exceptions.

## Acceptance contract

- The ordinary Python gate performs no model/network operation; explicit live
  qualification remains fail-closed and separately tested.
- Optional declared imports and undeclared imports have distinct, tested outcomes;
  self-host replication reaches its intended source-drift assertion.
- Lifecycle-driver and sample-runner pins can both be reviewed and recorded through
  deterministic commands, and version checking rejects stale closures.
- Parent, child, owned-resource, template, and typed-dependent skill changes produce
  the expected impact set. A projected parent cannot absorb child sentinels.
- A freshly initialized project has no unresolved skill references, and catalog/template
  parity or subset membership is mechanically enforced.
- Table-driven tests cover Linux, macOS, and Windows roots, relative-XDG rejection,
  redirected Windows folders, overrides, legacy migration/conflict, short staging, and
  event-state separation on any development host.
- Wheel/zip static resources continue to load through `importlib.resources`.
- Connector contract tests prove schemas, lifecycle transitions, errors, and MCP/CLI
  parity without invoking an LLM for deterministic transformations.
- Every host-prerequisite SBOM validates as CycloneDX 1.7 and matches its path tuple;
  dependency decline changes nothing, consent executes only declared commands, and
  unsupported tuples name the SBOM porting directory.
- A clean-checkout `make install` succeeds on Ubuntu, macOS, and Windows using the
  tuple's declared native manager and an isolated host-native or explicit prefix.
- Focused tests pass first, then `make python-check`, `make skills-check --all`, project
  validation, and the exact release commit's Ubuntu/macOS/Windows CI matrix.
- The operator-declared `literate.workers.json` CPU/GPU Linux and Windows workers are
  probed through `litai worker` and run applicable platform shards without recording
  credentials, private hostnames, or raw routing configuration.

## Scope boundaries

This program does not rewrite working source-generation subsystems, require optional
packages in core environments, replace logical repository paths with host-native ones,
or centralize target/kernel protocol constants into host config. Live generation and
semantic document composition remain model work; parsing, custody, identity, schema,
and deterministic verification do not.
