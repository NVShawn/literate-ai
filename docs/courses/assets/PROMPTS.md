CLI/API fallback. The original transparent PNGs are stored beside this file.

## LitAI

Use case: illustration-story. Asset: recurring portrait for a technical
instructional video. Original adult female expert guide personifying Literate
AI; capable, friendly, quietly confident. Waist-up, three-quarter angle,
expressive face, short dark teal hair, practical navy jacket with teal accent.
Clean high-end 2D editorial animation art, crisp silhouette, restrained
shading, centered transparent cutout, no props, text, logos, watermark, or
resemblance to a real person.
