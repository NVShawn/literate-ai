# Lab 00: Grumpy counter

Open `index.html`. Move the slider and watch modular arithmetic complain in color.
This first lab introduces readable authority, a tiny DAG, visible behavior and an
acceptance statement without requiring a Literate AI installation.

Read the [Component specification](component.md), inspect the [DAG data](lab.json) and
[implementation](main.js), then open the [standalone artifact](index.html).
