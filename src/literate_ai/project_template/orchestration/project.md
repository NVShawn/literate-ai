# Repository orchestration project

## Goals

Own exact child repository pins and declared cross-project dependencies while
preserving each child's independent source, authority, tests and release history.

## Dependencies

Child repositories are identified by the root project manifest's exact pins.
This root does not inherit their catalogs or claim their release readiness.

## Completeness

Root onboarding and persistent repository authority are scaffolded. No child
execution, compatibility, acceptance or publication is established by scaffolding.

## Current work

Qualify initialization, current-pin/root graph integration and reviewed refresh
before relying on those capabilities. Record subsequent project-specific goals
and release requirements here; never replace child requirements with root guesses.

## Completed work

No generated Component, child acceptance or versioned release is claimed.
